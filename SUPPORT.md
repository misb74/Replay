# Getting help

Replay is an early-stage macOS project maintained on a best-effort basis.

- For setup and expected behaviour, start with the [README](README.md) and the [architecture map](docs/architecture.md).
- For a reproducible bug, use the bug report template.
- For a product idea, use the feature request template.
- For a suspected vulnerability or privacy leak, follow [SECURITY.md](SECURITY.md) and report it privately.

Before sharing diagnostics, remove names, account details, file paths, URLs, credentials, recordings, screenshots, transcripts, workflow artefacts, and run logs that could identify a person or organisation. A small synthetic example is usually the safest way to get help.

There is no guaranteed response time for general support. Clear reproduction steps and a passing or failing test make an issue much easier to investigate.
